# 封面制作与复核

## 成品标准

- 横版1880×800，精确2.35:1。主体铺满，主标题与关键副标题完整、清楚，缩略图可读，人物头脸及主要场景完整。
- 禁止为了兼容方形而把整张首页缩成中间小图、四周补大留白；禁止直接拉伸16:9首页。
- 方形取景单独检查，优先保留核心标题。不能同时容纳全部文字时记录限制，不缩小横版主体迁就方形。

## 裁切或重设计

先查看最终课件第一页。默认靠上裁切；用 `--cover-focus-y` 调整垂直取景，0靠上、0.5居中、1靠下。参数只是取景位置，不表示图片已通过美观检查。

出现以下任一问题，不勉强交付裁切图：标题/关键副标题受损，人物头脸被截断，主体失衡、画面拥挤，或缩略图难以识别。提取原封面的准确文字、主题、配色、字体气质、插画风格和主要场景，按2.35:1重新组织图文。可通过可用图片生成/编辑工具重新绘制；原首页是内容与风格参考，不要求保留所有元素的原位置。

重设计不增加课件没有的主题、年级、资料或效果承诺。完成后逐字核对文字，检查人物、构图和实际尺寸；保存 `封面重设计原图.png`、设计依据和实际提示词。通过 `--cover "审核封面.png"` 交给文章脚本统一输出。更换独立封面不修改原课件第一页和正文。

## 批量替换已有封面

仅对需要从首页重新裁切的文章使用：

```powershell
python scripts/refresh_covers.py --root "文章根目录" --review "新的审核目录"
```

脚本从各文章的 `pages/01.jpg` 准备横图、默认居中方形检查图和清单。可用 `--focus-map "裁切位置.json"` 指定位置，JSON键为相对文章目录（使用 `/`），值为0至1。

逐张审核通过后：

```powershell
python scripts/refresh_covers.py --review "审核目录" --apply --backup "新的旧封面备份目录"
```

脚本在替换前核对来源、旧封面与审核图指纹，保留旧版和替换清单。审核文件有变化则重新准备，不能修改图片后跳过指纹检查。该脚本只做裁切，**不会自动重设计，也不会自动保护混在输入目录中的重设计封面**；重设计文章应单独处理并沿用审核成品，不能放入随后自动裁切覆盖的批次。批量替换不重建Word和Markdown正文。

## 后台与示例

`封面方形裁切检查.png`只是默认居中取景参考，可能裁掉两侧文字，不代表后台验收通过。后台分别查看横版和方形，必要时移动方形裁切框；保存草稿后刷新确认。更新本地文件不会自动更新已保存的草稿。

例如，原首页的标题居上、母子场景居下，裁成横图会截断人物：保留原标题、暖色水彩与书房场景，重排为左侧标题、右侧完整母子半身，比硬裁或缩图补白更适合横版封面。不要将这个示例中的标题或场景套给其他课件。
