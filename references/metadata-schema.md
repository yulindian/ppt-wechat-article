# 每篇文章的内容配置

保存为 UTF-8 JSON。`file` 相对于产品来源文件夹，必须是实际存在的交付资料。`intro` 只放教学导语，不重复写资料清单和“下面按照上课顺序完整展示课件”；这部分由脚本统一生成。

`intro` 为120–200字的一个自然段，字数不包含脚本追加的资料清单和固定展示句。介绍面向备课老师，语言像同事间推荐课件，避免教案式的流程复述。可直接使用以下提示词：

```text
根据完整课件，为面向备课老师的公众号文章写一段课件介绍。

用与本课有关的真实学生表现或课堂情境自然开头，带出主题，以及希望帮助学生理解什么、尝试做什么。选取课件中2—3个有代表性的内容或活动融入介绍，不逐页复述，不列教学流程，不要求每篇都使用相同结构。

语气像老师向同事介绍一份课件，亲切、具体、有分寸。不刻意设问或制造焦虑，不堆砌抽象概念，不反复使用“首先、其次、随后、最后”。避免“本课件旨在”“通过……培养……”“赋能”“全面提升”等套话。不夸大效果，不编造课件中没有的内容。

只输出120—200字的一个自然段，不解释写作过程，不手动加首行空格，不添加标题、Markdown格式、配套资料清单或“下面按照上课顺序完整展示课件”。资料清单和固定展示句由排版脚本在同一段末尾追加。
```

如果没有发言稿或教案，删去该项并同步调整摘要。标题前半按真实学年段、主题班课主题或教材内容写；后半使用最终课件名称。来源课件没有的教学步骤、资料与效果不得写入标题、摘要或导语。
