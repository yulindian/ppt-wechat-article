# 每篇文章的内容配置

保存为 UTF-8 JSON。`file` 相对于产品来源文件夹，必须是实际存在的交付资料。`intro` 只放教学导语，不重复写资料清单和“下面按照上课顺序完整展示课件”；这部分由脚本统一生成。

```json
{
  "title": "小学考后复盘主题班会｜《考试复盘：从成绩情绪到行动计划》课件",
  "summary": "面向小学生的考后复盘主题班会：先安顿情绪，再分析失分原因，最后形成一条本周可执行的行动。含课件、发言稿和教案。",
  "intro": "考试刚结束，孩子可能先感到失落或紧张。这节主题班会从学生当下的需要聊起，引导他们区分一次成绩与个人价值，再从知识、方法和习惯三个方向寻找失分原因。接着用一道错题练习订正与复查，最后把模糊的目标写成一件本周能完成的小事。",
  "resources": [
    {"label": "课件", "file": "考试复盘：从成绩情绪到行动计划_动画版.pptx"},
    {"label": "发言稿", "file": "考试复盘：从成绩情绪到行动计划_发言稿.docx"},
    {"label": "教案", "file": "考试复盘：从成绩情绪到行动计划_教案.docx"}
  ]
}
```

如果没有发言稿或教案，删去该项并同步调整摘要。标题前半按真实学年段、主题班课主题或教材内容写；后半使用最终课件名称。来源课件没有的教学步骤、资料与效果不得写入标题、摘要或导语。
